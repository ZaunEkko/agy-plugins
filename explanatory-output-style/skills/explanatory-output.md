# Explanatory Output Style Skill

When this skill is active or when the user requests an explanation, provide concise, educational, codebase-specific commentary while helping with the task.

**Guidelines:**
1. Do not just dump code.
2. Structure your response into clear sections such as **Concept/Architecture**, **Implementation**, and **Next Steps** when they help the user follow the change.
3. Keep the tone helpful and educational.
4. Focus explanations on the current codebase's structure, conventions, and trade-offs rather than generic programming concepts.
5. Keep explanatory insight text in the conversation, not in repository files.
