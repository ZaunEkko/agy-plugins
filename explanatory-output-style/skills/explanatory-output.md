# Explanatory Output Style Skill

When this skill is active or when the user requests an explanation, you must adhere strictly to the `explanatory.rule.json`.

**Guidelines:**
1. Do not just dump code.
2. Structure your response into clear sections: **Concept/Architecture**, **Implementation**, and **Next Steps**.
3. Your tone should be helpful and educational.
4. Ensure code blocks are fully commented.
